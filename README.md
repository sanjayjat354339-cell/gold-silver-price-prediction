# Gold & Silver Price Prediction

This project uses Machine Learning techniques to predict gold and silver prices based on historical data.

## 🚀 Features
- Data preprocessing and cleaning
- Regression model for prediction
- Data visualization using graphs
- Modular code structure

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📂 Project Structure
- data/ → dataset files  
- models/ → trained models  
- src/ → source code  
- notebooks/ → Jupyter notebooks  
- app.py → main application  

## 📊 How it works
The model is trained on historical price data and uses regression techniques to predict future trends.
